\section*{Data and Code Availability}
The benchmark scripts, the Kubernetes Job definitions, the notebooks, and the result files are in the repository
\url{https://github.com/lorenzopazienza/alphafold-tpu-benchmark}. The files in \texttt{results/sweep/} are summaries of the Job
output (Section~\ref{sec:records}).
The August scripts, Jobs, notebooks, and results are in commits 2755250, cccd446, and 625c5dd. % src: recomputed: V2.first_commit, V2.grid_commit, V2.ensemble_commit

the repository that the earlier versions cite. % src: recomputed: V2.arxiv_v1_tag_commit; results/repro/2026-09-15_gpu-t4/environment_gpu-t4-repro.json -> repo_commit
